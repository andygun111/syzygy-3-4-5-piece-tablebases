# syzygy-3-4-5-piece-tablebases
These are Syzygy tablebases.
They provide exact WDL (Win Draw Loss) & DTZ (Distance to Zero)  information for positions with up to 5 pieces.

File naming scheme is *K__vK__*, just replace underscores with piece letters.
*(Q = Queen, R = Rook, B = Bishop, N = Knight, P = Pawn)*

Everywhere I saw had broken links or didn't work for other reasons, so this is a stable location to download the files...
